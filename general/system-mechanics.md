# 机制与角色杂项

本文按 PDF 原表的“序号 / 标题 / 内容”结构整理第 5–6 页。数字方向和按键缩写见[指令记法](input-notation.md)，相关概念见[格斗术语表](glossary.md)。

> PDF 创建于 2025-03-09，但没有标明对应的游戏版本。下列帧数、伤害和资源数值是资料快照，使用前应在当前版本的训练模式中复核。

## 通用机制

| 序号 | 标题 | 内容 |
| ---: | --- | --- |
| 1 | 移速 | 每个角色的前走、后走速度不同，前冲和后退的移动距离也不同。 |
| 2 | 后后 | 后退回避从发生到恢复自由行动都保持地面判定；发生后第 1-15F 对投无敌。 |
| 3 | 起跳 | 通常角色有 4F 起跳准备；莉莉和桑吉尔夫为 5F。起跳准备期间对投无敌。 |
| 4 | 落地 | 正常跳跃后有 3F 落地硬直。空跳落地时可以防御或拆投；空中出招后会有 3F 落地收招硬直，可以被确反康。 |
| 5 | 判定 | 前冲、后退回避和空跳的全过程都没有被康判定。 |
| 6 | 投 | 普通投发生 5F、持续 3F、收招 23F，全程 30F。投技可以触发确反康。 |
| 7 | 连投 | 大部分角色在版边仍可形成连投循环。多数角色可以用后退回避躲投，成功后的局面可能有利，甚至可以确反。 |
| 8 | 拆投 | 拆投受理时间为 9F。拆投后双方被推开，资料以大约“隆的两个身位”描述距离。 |
| 9 | 对投无敌 | 起跳准备期间对投无敌；后退回避第 1-15F 对投无敌；起身后有 1F 对投无敌；防御或受创硬直结束后有 2F 对投无敌。 |
| 10 | 普康 | 普通康额外增加 2F 有利。绿冲过程中、隆的 `22P`、杰米喝酒等行动处于发生阶段时，只会被打出普通康。 |
| 11 | 确反康 | 确反康额外增加 4F 有利。普通投确反康会出现特写；下重脚确反康会延长倒地时间。 |
| 12 | 康加伤 | 通常技和必杀技发生普通康或确反康时，伤害增加 20%。普通投的普通康不增伤，确反康增加 70%；指令投的普通康不增伤，确反康增加 15%。 |
| 13 | 倒地起身 | 只有原地起身和后起身两种，二者起身时间相同。倒地瞬间按任意两个键可选择后起身。 |
| 14 | 强制倒地 | 被具有强制倒地属性的攻击命中后只能原地起身，例如下重脚。 |
| 15 | 霸体技 | 部分 OD 招式带霸体。资料列举桑吉尔夫蓄重拳、本田 OD 头槌、玛丽莎的多个必杀技和卢克 OD 下前脚为例。 |
| 16 | D 反 | 斗气反攻可以破霸体，例如用于击破对手的斗气迸放。 |
| 23 | 加帧 | 绿冲后的拳脚命中会额外增加 4F 受创硬直；普通康额外增加 2F；确反康额外增加 4F。 |
| 24 | SA1 | 资料称 SA1 只能由通常技取消。大部分 SA1 在发生阶段没有飞行道具无敌，但有打击和投技无敌。 |
| 25 | SA2 | 通常技和满足条件的 OD 必杀技可以取消到 SA2。 |
| 26 | SA3 | 通常技、必杀技和满足条件的 OD 必杀技可以取消到 SA3。动画期间游戏时间暂停；进攻方仍可恢复约 2-2.2 格斗气，防守方停止恢复。 |
| 27 | CA | 体力低于 25% 且拥有 3 格超杀槽时，SA3 变为 CA。演出和画面效果变化，伤害增加 500。 |
| 28 | 破霸体 | SA 中的飞行道具和打击攻击都能破霸体。 |
| 29 | 斗气槽超额使用 | 尚未进入枯竭时，可以让 OD 招式超额消耗剩余斗气。斗气不足 0.5 格时尝试超额裸绿冲或普通格挡会原地枯竭，但满足时机的完美格挡仍能生效。 |
| 30 | 斗气槽恢复暂停 | 非枯竭状态下防御攻击约暂停恢复 1.5 秒；格挡挥空约暂停 4.5 秒；格挡成功约暂停 1 秒。被斗气迸放等招式确反康后也会暂停一段时间。绿冲取消后约暂停 2.5 秒，裸绿冲后约暂停 4.5 秒，使用其他斗气招式后约暂停 2.5-3 秒。 |
| 31 | 斗气槽恢复速率 | 原地不动的恢复速率记为 100%；前走约为 150%；普通受击或处于空中时约为 60%。绿冲连段中，只有前走能获得额外斗气恢复。 |
| 32 | 斗气槽消耗 | 确反康会额外削减斗气。斗气反攻无论命中还是被防都不削减对手斗气。SA1、SA2、SA3、CA 命中时分别削减 0.5、1、1.5、2 格；SA 确反康不会额外增加削减量。 |
| 33 | 斗气迸放削斗气 | 斗气迸放被防削减 0.5 格，普通命中削减 1 格，普通康削减 1.2 格，以霸体承受对手斗气迸放后命中削减 1.5 格。 |
| 34 | 斗气迸放连段 | 带入连段的斗气迸放没有弹墙性能。资料还指出，在版边已经处于防御硬直时再防御斗气迸放，不会触发破防。 |
| 35 | 绿冲浮空 | 绿冲攻击可以让空中的对手重新获得可追击的浮空属性。 |
| 36 | 裸绿冲 | 按住格挡至少需要 3F。最速取消格挡进入滑行时，准备动作 8F；滑行后不出招，第 24F 起可以防御、跳跃、前冲或后退回避。完全不操作时，整个滑行持续 45F。 |
| 37 | 绿冲取消 | 绿冲滑行中可以取消到通常技、特殊技、必杀技、斗气迸放和 SA；整个动作结束前不能取消到斗气招架。 |
| 38 | 绿冲取消 | 绿冲取消的滑行准备动作比裸绿冲多 1F。 |
| 39 | 斗气反攻 | 原表写作“斗气反击”：发生 20F、持续 3F、完全无敌共 22F；收招可以被打，被防 -8F。 |
| 40 | 枯竭状态 | 从 0 恢复到 6 格默认约需 21 秒。因格挡进入枯竭的瞬间可以防御，但不能拆投。枯竭中前走仍会提高恢复速度，约为默认的 1.5 倍以下。 |
| 41 | 枯竭防御 | 对枯竭对手的攻击被防后，进攻方硬直差额外增加 4F，命中时不变。必杀技磨血伤害为原伤害的四分之一。 |
| 42 | 斗气招架 | 第 1-2F 是完美格挡判定，第 3-8F 是普通格挡判定。在前一招硬直中提前按住格挡，第 1F 开始就是普通格挡。格挡被普通投会触发确反康，造成 2040 伤害，并暂停斗气恢复 4.5 秒。 |
| 43 | 斗气招架派生 | 普通格挡后可以派生绿冲和斗气反攻。 |
| 44 | 完美格挡 | 可以点按或按住，但都必须在攻击到达前输入。发生 1F、持续 2F。完美格挡最低点安全跳后为 +2F，因为最低点安全跳有 1F 空中判定和 3F 落地收招硬直。完美格挡后的连段强制以 50% 伤害修正起手。 |
| 45 | 完美格挡修正 | 完美格挡后的连段伤害修正依次为 50%、40%、30%，之后继续递减。 |
| 46 | 版边逆向 | 对手紧贴版边时无法从其背后落下，因此不能形成通常的跳跃逆向。 |
| 47 | 最快的拳 | 最快的通常技发生为 4F。资料中的普通中段最差为被防 -3F，因此不会被通常技确反。 |
| 48 | 轻攻击连打 | 轻攻击之间的连打取消都有缝隙，并非联防。 |
| 49 | 受击框 | 蹲姿防御时的受创判定比站姿防御更大。 |
| 50 | 预输入 | 指令预输入窗口为 4F，因此名义上的 1F 目押实际有 5F 的输入受理时间。 |
| 56 | 打 VS 投 | 打击和投技在同一时刻相撞时，打击获胜。 |
| 57 | 波动等级 | 飞行道具有攻击等级差异，通常为 SA 飞行道具高于 OD 飞行道具，OD 高于普通飞行道具。高等级飞行道具可以贯穿低等级飞行道具。 |
| 60 | SA 修正和保底 | SA1、SA2、SA3/CA 的最低伤害修正分别为 30%、40%、50%。由必杀技取消到 SA3/CA 时，额外增加 10% 修正。 |
| 61 | 绿冲修正 | 裸绿冲起手采用正常连段修正。绿冲取消会让后续每一下在原有基础上额外修正 15%，也就是伤害乘以 85%；多次绿冲取消仍按 15% 计算。 |
| 62 | 迸放修正 | 版边斗气迸放破防后的每一下额外修正 20%，也就是伤害乘以 80%。 |
| 63 | 现代模式 | 现代模式快捷必杀技的伤害是手动指令版本的 80%。 |
| 66 | 练习场重置键 | 可以在快捷设置中指定重置键。以 `R` 为例：`R` 返回上一次设置的位置；`R+2` 返回版中默认位置并重置“对战环境”位置；`R+4/7` 为左版边 1P 贴版；`R+1` 为左版边 2P 贴版；`R+6/9` 为右版边 2P 贴版；`R+3` 为右版边 1P 贴版；`R+8` 在中央换位，1P 位于右侧。 |
