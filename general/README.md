# 通用知识

这里收录主语是游戏机制、通用学习方法或跨角色比较的知识。判断归属时看笔记要说明什么，不以正文是否出现角色名为准。

## 收录范围

- 不依赖单一角色的游戏机制与通用方法
- 适用于多个角色的学习与训练知识
- 以全局比较为目的的跨角色资料

例如，“对空的通用原理”和“全角色普通投距离对比”属于通用知识。

## 不收录

- 某个角色的招式、能力、连段或策略
- 从某个角色出发分析的对局知识

这些内容应放入对应的[角色知识](../characters/README.md)。需要引用通用结论时链接到这里，不复制正文。
