# 指令记法

本文统一说明知识库中使用的数字键盘方向、拳脚缩写和连段符号。除非另有说明，方向以角色面向右侧为准；角色换边后，前后方向也要相应反转。

## 方向

```text
7 8 9    ↖ ↑ ↗
4 5 6    ← · →
1 2 3    ↙ ↓ ↘
```

| 数字 | 方向 |
| ---: | --- |
| `8` | 上 |
| `2` | 下 |
| `4` | 后 |
| `6` | 前 |
| `7`、`9` | 后上、前上 |
| `1`、`3` | 后下、前下 |
| `5` | 不输入方向，也叫回中 |

资料中的 `24` 和 `26` 是简写输入，分别表示从下向后、从下向前转动；实际操作会经过对应的斜方向。

## 按键与招式

| 缩写 | 含义 |
| --- | --- |
| `J` | 跳跃（Jump） |
| `L`、`M`、`H` | 轻、中、重 |
| `P`、`K` | 拳、脚 |
| `EX` | 资料原文的强化招式写法，在《Street Fighter 6》中对应 OD |
| `SA1`、`SA2`、`SA3` | 消耗对应格数超杀槽的 Super Art |
| `CA` | 体力较低时强化的 SA3 |

方向、强度和拳脚可以组合：

- `5LP`：站轻拳
- `2HP`：蹲重拳
- `6MK`：前中脚
- `J.HK`：跳重脚
- `26LP`：从下向前输入后按轻拳
- `[2]8K`：先蓄下，再输入上加脚
- `[4]6P`：先蓄后，再输入前加拳

## 连段符号

| 符号 | 含义 |
| --- | --- |
| `-` | 按顺序衔接后续招式；具体是取消还是目押要看招式性能 |
| `>` | 按固定顺序输入的 TC 技或特定派生关系 |
| `/` | 根据资源、位置或目标状态选择其一 |
| `……` | 省略前面或后面的连段部分 |

例如：

```text
2LP - 2LK - 2LP - 26LK
```

表示依次输入蹲轻拳、蹲轻脚、蹲轻拳，再从下向前输入并按轻脚。
