# 格斗术语表

本文整理常见格斗游戏术语，并以《Street Fighter 6》的用法为主。部分词语是玩家社群中的俗称，不一定是游戏内的官方名称。

## 招式与输入

| 术语 | 解释 |
| --- | --- |
| 沁 | 疯狂按键，也就是常说的“乱按”或“搓键”。这是资料原文采用的俗称。 |
| 通常技 | 直接按拳或脚使出的攻击；部分资料也把方向键加拳脚的特殊技纳入广义的通常技。 |
| 特殊技 | 通常以方向键加拳或脚使出，往往具有吹飞、倒地、中段等额外属性。 |
| 必杀技 | 通过复数方向指令加拳或脚使出的招式。日常交流中通常不包含超必杀技。 |
| OD 必杀技 | 强化版必杀技，也常被叫作 EX 必杀技。通常同时按两个拳或两个脚使出，消耗 2 格斗气。 |
| 超杀 | 消耗超杀槽使出的 Super Art，简称 SA。按消耗量分为 SA1、SA2、SA3；体力低于 25% 时，SA3 会变为 CA。 |
| 复合 | 在很短的时间内输入多种指令，让同一套输入能够覆盖多种结果。 |
| 取消 | 在前一招的硬直结束前使出后一招，以后一招取代前一招剩余的收招时间。 |
| 目押 | 等前一招完全结束后，在允许的时间窗口内接上后一招。 |
| TC 技 | Target Combo，目标连段。按固定顺序快速输入指定拳脚，即可让这些招式相互取消。 |
| 构 | 一种特殊姿态。角色进入构以后，即使输入和普通状态相同，也可能使出性能不同的招式。 |
| 派生技 | 使出某一招后，再追加特定输入才能发动的后续招式。 |

## 判断、命中与攻防属性

| 术语 | 解释 |
| --- | --- |
| 确认 | 通过画面或声音判断攻击是否命中、被防或打康，再选择对应的后续行动。 |
| 确反 | 确认后进行反击。 |
| 凹 | 不做确认，直接使出带无敌起手的招式，赌对手继续进攻。 |
| 上段攻击 | 站姿防御和蹲姿防御都能防住的地面攻击。 |
| 中段攻击 | 蹲姿防御无效，通常需要站姿防御。 |
| 下段攻击 | 站姿防御无效，通常需要蹲姿防御。 |
| 打康 | 在对手行动的特定阶段命中，触发 Counter Hit 或 Punish Counter。 |
| 普通康 | Counter Hit，简称康。通常是在对手招式的发生或持续阶段命中。 |
| 确反康 | Punish Counter，简称 P 康。通常是在对手的收招硬直阶段命中。 |
| 攻击判定 | 招式能够命中对手的有效范围，也常叫攻击框。 |
| 被攻击判定 | 角色能够被攻击命中的范围，也叫受创判定或受击框。 |
| 无敌 | 在一段时间内没有某类被攻击判定。常见类型有上半身无敌、下半身无敌、飞行道具无敌、打击无敌、投技无敌和完全无敌。 |
| 霸体 | 招式进行中承受一定次数的攻击也不会被打断。可被破霸体属性或超过承受次数的多段攻击击破。 |
| 破霸体 | 能直接击破霸体的属性，或用足够多的攻击段数耗尽霸体。SA、CA 等招式常带有破霸体能力。 |
| 强制倒地 | 倒地后只能原地起身，不能后起身。 |
| 破防 | 击破防御，或用不可防御的手段命中对手。 |
| 当身 | 招式本身先进入接招状态；满足触发条件后，自动派生反击等后续效果。 |

## 帧数与硬直

| 术语 | 解释 |
| --- | --- |
| 帧数 | 格斗游戏的基本时间单位。《Street Fighter 6》通常以每秒 60 帧运行，因此 1 帧约等于 1/60 秒。 |
| 发生时间 | 从开始出招到攻击判定首次出现所需的时间，也叫发生帧或起手。 |
| 持续时间 | 攻击判定从出现到消失的时间，也叫持续帧或攻击帧。 |
| 收招时间 | 攻击判定结束后，到角色恢复自由行动所需的时间。 |
| 硬直 | 角色因出招、受击或防御等原因暂时不能自由行动的时间。 |
| 联防 | 防守方持续处于防御硬直，两个攻击之间没有可以自由行动的空隙。 |
| 偷帧 | 用招式靠后的持续帧命中对手，从而减少自身剩余收招并获得更多有利帧。可用于偷帧连段或偷帧压制。 |
| 暗转时间 | 超必杀发动时画面变暗或播放特写、双方暂时不能行动的时间。 |

## 连段与伤害

| 术语 | 解释 |
| --- | --- |
| 连段 | 通过取消或目押让多次攻击连续命中，使对手无法在中途防御或行动。 |
| 二段确认 | 利用两次攻击提供的时间判断是否命中，再决定是否接入预先计划的后续。 |
| 修正值 | 连段中的伤害缩放。伤害会根据起手、连段段数和特定招式的修正规则降低。 |
| 打修正 | 原资料的说法：在连段末尾放弃直接击倒或击晕，改用重新起攻来争取更高的后续收益。通常也可理解为一种重置（Reset）思路。 |
| F 式 | 利用角色由站防切到蹲防时，站姿受创判定短暂保留的现象，以空中攻击命中这个判定。 |
| 升中段 | 在跳跃上升阶段快速出空中攻击。与 F 式不同，部分升中段可以直接命中蹲姿的大体型角色。 |

## 立回与进攻

| 术语 | 解释 |
| --- | --- |
| 牵制 | 用较远的招式阻止对手接近，或限制对手可活动的空间。 |
| 压制 | 用招式组合维持进攻优势，限制防守方行动。压制不一定等于全程联防。 |
| 压起身 | 击倒后在对手起身前布置攻击、投或斗气迸放等行动，压制对手的起身选择。也叫起身压制或 Okizeme。 |
| 摸奖 | 预先放出拳脚或必杀技，期待对手进入攻击范围；出手时并不确定一定会命中。 |
| 安全跳 | 用特定时机的低点跳攻击压起身。对手防御时攻击成立；对手使出无敌技时，进攻方能及时落地防御。 |
| 逆向 | 从对手背后或另一侧命中，迫使对手改用相反方向防御的攻击。 |
| 立回 | 广义指为了取胜而进行的全部攻防决策；狭义通常指双方在中距离围绕空间、距离和招式进行的拉扯。 |
| 预读 | 观察并记住对手习惯，提前准备相应对策。也叫读或下载。 |
| 见切 | 看到对手行动后，再依靠反应采取对策。 |
| 先置 | 预判对手的行动，提前放出持续时间或判定合适的招式，使对手的行动失败或被打康。 |
| 对置 | 针对对手将要使用的招式，利用更快的发生、更强的判定或有利的相杀结果主动迎击。 |
| 差合 | 确认对手招式挥空后，在其收招硬直中命中。也叫 Whiff Punish。 |

## 位置与特殊受击状态

| 术语 | 解释 |
| --- | --- |
| 击退距离 | 攻击命中或被防时，防守方被推开的距离。靠近版边时，部分位移会转移到进攻方身上。 |
| 腹崩 | 角色捂腹、缓慢跪倒的受击状态。部分重攻击造成确反康时会触发。 |
| 墙崩 | 对手靠近版边并防住斗气迸放时，被撞上墙后进入可追击的破防状态。 |
| 贴墙 | 斗气迸放命中靠近版边的对手后，使其撞墙并进入可追击状态。 |
| 滑地 | 某些招式让对手倒地滑行或滚动，并允许进攻方继续追击。 |

## 斗气系统

| 术语 | 解释 |
| --- | --- |
| 斗气 | 《Street Fighter 6》的 Drive Gauge。开局有 6 格，可自行恢复；用尽后进入枯竭状态。 |
| 斗气迸放 | Drive Impact，简称迸放或 DI。按重拳加重脚发动，消耗 2 格斗气，带两次霸体；在版边对防御中的对手可造成墙崩。 |
| 枯竭状态 | Burnout。斗气槽为空时进入；防御硬直增加，在版边被斗气迸放墙崩时会眩晕。 |
| 斗气招架 | Drive Parry，简称招架或格挡。按中拳加中脚发动，可应对大多数打击和飞行道具，但会被投克制。 |
| 普通格挡 | 持续按住斗气招架，消耗至少 0.5 格斗气并继续按时间消耗。 |
| 完美格挡 | Perfect Parry。在对手攻击命中的前一瞬间发动斗气招架，成功时出现时停特效，消耗 0.5 格斗气。 |
| 斗气冲锋 | Drive Rush，简称绿冲，分为裸绿冲和绿冲取消。 |
| 裸绿冲 | 从斗气招架状态输入前前发动，消耗 1 格斗气。 |
| 绿冲取消 | 可取消的通常技命中或被防后输入前前发动，消耗 3 格斗气。 |
| 斗气反攻 | Drive Reversal。在防御或普通格挡中输入前加重拳、重脚发动，消耗 2 格斗气。 |

## 来源与时效

整理自《查查三的格斗指南——新手必看的拳脚解析与连段建议【不知火舞】》第 1–2 页。PDF 元数据显示文件创建于 2025-03-09，但没有标明对应的游戏版本。

本文调整了原文的分类和表述，但保留资料中的定义和数值。斗气消耗、招式属性等内容可能随版本更新，应以当前游戏内训练模式为准。
