# 角色知识

这里按角色收录主语是具体角色、该角色能力或该角色视角的知识。每名角色使用一个独立目录，只在开始记录该角色时创建。

## 收录范围

- 某个角色的招式、能力、连段与策略
- 某个角色如何运用通用机制
- 从某个角色出发分析的对局知识

例如，“隆使用升龙拳对空的时机”和“隆对肯的对局策略”属于隆的角色知识。反方向的“肯对隆”属于肯的角色知识。

## 不收录

- 不依赖单一角色的游戏机制与通用方法
- 以全局比较为目的的跨角色资料

这些内容应放入[通用知识](../general/README.md)。需要引用通用结论时链接到对应笔记，不复制正文。

## 目录命名

角色目录采用官方英文角色名的小写短横线形式，例如 `ryu`、`chun-li` 和 `m-bison`。中文名、日文名和玩家俗称可用于正文检索，不创建重复目录。
