# 不知火舞入门

本文整理不知火舞（Mai Shiranui）的常用拳脚、入门连段和压起身建议。招式名称不明确的地方保留数字指令，读法见[指令记法](../../general/input-notation.md)。

> PDF 创建于 2025-03-09，但没有标明对应的游戏版本。以下帧数、伤害和路线是资料快照，练习前应在当前版本的训练模式中复核。

本文使用的格斗概念见[格斗术语表](../../general/glossary.md)。

## 基础数据

- 体力：10000
- 难度以五颗星为最难，是资料作者给出的学习难度，不代表招式强度。

## 连段路线

下列路线中的 `EX` 保留资料原写法，实际就是 OD 招式。

### 基础路线

1. 重拳起手

   ```text
   5HP - 24HP - 26LK / 重升龙
   5HP - EX24P - SA1 / CA
   ```

   伤害可观，可接在跳攻击或斗气迸放确反康之后。`24HP` 打不到蹲姿；`EX24P` 后可以接 SA1。

2. 安全磨血与摸奖

   ```text
   5HP - 26LP / EX26P
   ```

   通常用于磨血或摸奖。OD 扇子共有两段，后续可以用跳跃、下段等行动形成多择。

3. 轻攻击确认

   ```text
   2LP - 2LK - 2LP - 26LK
   ```

   入门必备路线，主要难点在命中确认。资料建议钻石阶段掌握。

4. 不依赖站姿的路线

   ```text
   MP / 2MK / 5HP - EX26K - J.MP - J.24P
   ```

   不需要判断对手是否蹲姿，适合接在跳攻击或确定反击后。`J.MP` 后也可以接超杀。

5. TC 起手

   ```text
   LK > LK > LK - J.EX24P - 重升龙
   ```

   前三次轻脚即使被防也相对安全，操作难度较低。

### 进阶路线

6. 中距离下段摸奖

   ```text
   2MK - 绿冲取消 - 4HK - 2MP - 24HP - 必杀技
   ```

   `4HK` 可以强制对手站立。路线难点主要在下段确认和绿冲取消。

7. 火焰强化状态收尾

   ```text
   …… - 24HP - 24MP - 重升龙
   …… - EX24P - 24HP - 重升龙
   ```

   低资源、高伤害。资料建议顺势使用，不必为了进入火焰强化状态强求路线。

8. 长距离推版

   ```text
   J.HK - 5HP - EX24P - SA2 - 中升龙 / EX升龙 / SA1
   ```

   用于从版中后方推到远处并获得火焰强化状态。SA2 需要无缝衔接，否则后续 SA1 可能打不到。

9. 防住对手无敌升龙后的惩罚

   ```text
   2MP - 5HP - ……
   ```

   这是对手无敌技落空后的确反康起手，后续接入适合当前资源和位置的连段。

## 压起身

### 版中

```text
66 - 4HK
```

路线本身不难，难点在于先确认前面的击倒是否形成对应局面。资料建议钻石阶段掌握。

### 版边

```text
2MP 挥空 - 2MP - 2MP - 必杀技
```

第一个 `2MP` 挥空用于卡时间，第二个 `2MP` 偷帧；命中后可以连上第三个 `2MP`。
