# 不知火舞进阶备忘录

本文整理 Minato 波风水门的《【街霸6】不知火舞备忘录｜英格丽德版本》，重点保留可用于训练的决策框架和代表路线。原文包含大量按斗气、忍焰、位置细分的斩杀表，本文不逐条复制；需要精确查伤害时应回到[原始文档](https://zcn7u9of5z3o.feishu.cn/wiki/DI09wAEkKii85MkyJgqcJObGnUf)。

> 原文标注更新于 2026-07-02。版本更新可能改变帧数、伤害和连段成立条件，练习前应在训练模式复核。

数字方向、按键和连段符号见[指令记法](../../general/input-notation.md)，格斗概念见[格斗术语表](../../general/glossary.md)。

## 阅读约定

- 一气、二气、三气：原文对 SA1、SA2、SA3 的简称。
- 忍焰：不知火舞的强化资源；原文按 0-5 层区分路线。
- 方括号中的 `+N`：连段结束后的有利帧，用于选择压起身。
- 远版、近版、版边：连段开始或结束时与版边的相对位置。

## 进攻框架

```text
贴身       轻攻击确认 / 轻脚 TC
  ↓
中距离     2MK 摸下段 → 轻龙炎舞或绿冲取消
  ↓
较远距离   5HP 复合扇子 / 裸绿冲下段
  ↓
全屏       蓄力扇子掩护近身，同时准备对空
```

| 距离与目的 | 代表路线 | 训练重点 |
| --- | --- | --- |
| 贴身三点确认 | `2LP × 3 - 轻忍蜂` | 版中收尾约 +27，随后练习卡帧 `4HK`、下段、投和骗拆。 |
| 贴身版边伤害 | `2LP × 3 - 重升龙` | 收尾约 +31；用 `2MP` 卡帧后进入打投与防凹。 |
| TC 确认 | `轻脚 TC - 空箭` | 通常约 +41；有忍焰时约 +42，可转安全跳。 |
| 偷下段 | `2LK × 2 - 2LP - 轻忍蜂 / 重升龙` | 根据位置选择稳定倒地或更高伤害。 |
| 打康确认 | `LP / 2LP（打康）- 2MP - 重忍蜂` | 先确认轻拳打康，再接中拳。 |
| 中距离骚扰 | `2MK - 轻龙炎舞` | 无忍焰时注意距离和被防风险；有忍焰后更安全，并获得更好的压起身。 |
| 中距离绿冲 | `2MK - 绿冲取消 4HK - 2MP - 重龙炎舞 - 收尾` | 两点确认；`4HK` 被防后要准备处理双方最速招式相撞。 |
| 扇子复合 | `5HP - 轻扇子 / OD 扇子` | 轻扇子必须控制距离；OD 扇子用于进入后续多择。 |
| 远距离下段 | `绿冲 2LK - 2MP - 收尾` | 练习确认命中与被防后的相杀处理。 |
| 远距离绿冲 `4HK` | `绿冲 4HK - 2MP - 重龙炎舞 - 收尾` | 确认 `4HK` 命中；被防后约 +3，可以继续压制。 |
| 跳入 | 近至较远用 `J.MK - 5HP`；远距离用 `J.HK - 5HP` | 跳中脚路线不需要确认正逆；远距离改用跳重脚。 |

## 常用压起身

| 倒地优势 | 推荐选择 |
| --- | --- |
| 约 +27 | 前冲卡帧 `4HK`；前冲后走下段；前冲前走投；绿冲中段、`4HK` 或下段形成多择。 |
| 约 +30 | 前冲后微走轻拳或投；版边可以用轻拳卡帧接 `4HK`。 |
| 约 +35 | 轻忍蜂偷帧；或绿冲放帧使用中段、`4HK`、下段。 |
| +41 | 两次前冲卡帧后进入打投，或根据位置做伪安全跳。 |
| +42 | 直接练习安全跳；版中使用跳中脚，版边可用跳重拳接 `4HK`。 |

原文反复使用三个验证点：

- 能否后走防住无敌技，同时骗到延迟拆投。
- 绿冲轻拳能否防凹，以及是否会输给对手的 4F 或 5F 通常技。
- 偷帧招式命中后接什么、被防后双方分别有多少帧。

## 确反与差合

### 5HK 差合

| 位置与资源 | 代表路线 | 后续 |
| --- | --- | --- |
| 远版、零斗气 | `前冲 - 2LP - 重龙炎舞 - 中忍蜂` | 根据命中距离约 +24 至 +26。 |
| 远版、一斗气 | `绿冲 5HP - 重龙炎舞 - 中忍蜂` | 距离过远时比零斗气路线稳定。 |
| 近版 | `前冲 - 2LP - 重龙炎舞 - 轻忍蜂 - 中升龙` | 约 +30；有更多忍焰时可改重升龙提高收益。 |
| 近版、一斗气 | `绿冲 5HP - 重龙炎舞 - 轻忍蜂 - 升龙` | 用于提高推板并进入版边压起身。 |
| 近版、二斗气、0 忍焰 | `绿冲 5HP - 重龙炎舞 - 绿冲 2LP - 轻忍蜂 - 重升龙` | 约 +30，用于进一步增加推板距离。 |
| 近版、二斗气、1-3 忍焰 | `绿冲 5HP - 重龙炎舞 - 绿冲 2MP - 轻忍蜂 - 重升龙` | 1-2 忍焰约 +30，3 忍焰约 +33。 |

### 防住无敌技

优先先判断位置，再判断忍焰和斗气：

- 远版低资源：`5MK - 5HP - 重龙炎舞 - 轻忍蜂`。
- 有 2 层忍焰时，可用中龙炎舞收尾获得约 +42 的安全跳。
- 近版低资源：`5MK - 5HP - 重龙炎舞 - 升龙`。
- 有 OD 资源时，可用蓄力 OD 扇子、OD 忍蜂和空中追击增加伤害或推板。
- 版边可使用 `2HP - 4HK TC - 中升龙`。

### 其他确定惩罚

- 反斗气迸放：前冲两次后从 `5HP` 起手，根据位置选择中忍蜂或轻忍蜂加升龙。
- 墙崩：`5HP - 重龙炎舞 - 轻忍蜂 - 升龙`，根据迸放是命中还是被防调整升龙强度。
- 眩晕：跳重脚后选择 `4HK TC` 或重拳、双龙炎舞路线。
- 版中打拆投从 `2MP - 5HP` 起手；版边可改 `2HP - 4HK TC`。
- 斗气反攻被防后，从 `2MP - 5HP` 起手确反。

## 扇子与超杀

### 蓄力扇子

- 轻蓄力扇子飞得慢、弹跳短、落点近；重蓄力扇子相反；中蓄力和 OD 位于两者之间。
- 发出扇子后，根据距离选择绿冲、前冲或前跳近身，混合中下择和打投择。
- 裸蓄扇子容易被跳入，应在对手一次跳跃难以碰到的位置使用。
- 无忍焰时，蓄力扇子和 OD 扇子贴身被防约 -5，不适合直接压起身。
- 有忍焰时，蓄力扇子和 OD 扇子的被防帧改善，可以转为压制工具。
- 满蓄 OD 扇子适合跟随飞行道具近身，但仍要观察对空。

### 开一气

稳定入口包括：

- OD 龙炎舞取消一气：约 +30，版中可用蓄力扇子继续布置。
- `2MP - 一气`：约 +26，可根据位置接卡帧中拳、版边轻扇子或斗气迸放。
- 反迸、5HK 确反康、重龙炎舞、`4HK TC`、OD 空箭和 OD 忍蜂空中追击都能作为不同位置的一气入口。

## 其他倒地局面

| 来源 | 核心思路 |
| --- | --- |
| 前投 | 绿冲重脚处理原地起身；版边或确反康时，可改绿冲 `4HK`、放帧下段或前冲卡帧。 |
| 后投 | 根据原地起身和后起身分别确认绿冲重拳的命中帧；也可用绿冲 `4HK` 或下段。 |
| 空投 | 绿冲 `4HK`、放帧下段，或前冲卡帧后进入下段、投、骗拆。 |
| 地面 OD 升龙 | 绿冲放帧 `4HK` / 下段，近版可前冲卡帧。 |
| 斗气反攻 | 绿冲重脚、前走放帧、版边轻拳卡帧接 `4HK`，或直接迸放。 |
| 升龙对空 | 版中绿冲放帧，版边前冲微走后自由压制。 |
| 二气收尾 | 优势较大，可绿冲放帧重脚或近版轻忍蜂偷帧。 |
| 三气收尾 | 用前冲卡帧轻攻击，或绿冲 `4HK` / 下段继续进攻。 |

## 枯竭压制

- `2MP`、`6MP`、`5HP`、`2HP`、`5HK`、`4HK` 在对手枯竭时都能改善被防帧，其中 `2MP`、`2HP` 尤其重要。
- `2MK - 轻龙炎舞` 可以形成连续防御；有忍焰时轻龙炎舞的被防帧更好。
- 空箭、忍蜂和贴身 OD 扇子都可用于维持磨血，但要按距离与忍焰确认是否真正有利。
- 版边可循环轻攻击、中攻击、轻龙炎舞和 OD 扇子；原文强调这些路线存在缝隙，训练时要分别验证对手能否抢招或只能使用无敌技。

## 斩杀路线怎么选

原文按一气、二气、三气分别列出大量精确伤害。实战不必死记全部数字，可以按以下顺序决策：

1. 先确认当前超杀槽是否足够直接斩杀。
2. 再看斗气是否允许 OD 扇子、OD 龙炎舞、OD 忍蜂、OD 空箭或绿冲延长连段。
3. 根据忍焰层数决定是否加入第二次龙炎舞、空中追击或更强的升龙收尾。
4. 判断是否已经在版边；不少高伤路线只有版边成立，搬运路线则需要预估落点。
5. 训练时分别记录最低资源稳定路线和全资源最高伤路线，避免实战只记得条件苛刻的版本。

几个用于校准伤害量级的简单路线：

| 超杀 | 条件 | 代表路线 | 原文伤害 |
| --- | --- | --- | ---: |
| 一气 | 零斗气、0-1 忍焰 | `5MK - 5HP - 一气` | 3240 / 3480 |
| 一气 | 零斗气、版边、0-1 忍焰 | `2HP - 4HK TC - 一气` | 3720 / 3870 |
| 二气 | 零斗气、0 忍焰 | `5MK - 5HP - 重龙炎舞 - 二气` | 3960 |
| 二气 | 零斗气、2-3 忍焰 | `5MK - 5HP - 重龙炎舞 - 中龙炎舞 - 二气` | 4530 / 4630 |
| 三气 | 零斗气、0 忍焰 | `5HP - 三气` | 4960 |
| 三气 | 零斗气、1 忍焰 | `5HP - 重龙炎舞 - 三气` | 5060 |
